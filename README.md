# Cipherbox
box of modular ciphers that ran locally on python

# Requirements
- Python
- cryptography library 
~~~
pip install cryptography
~~~

# Usage
1. Download [cipherbox.zip]()
2. Unzip anywhere where it is convenient for you (e.g. /home/user)
3. In the terminal go into the folder you unziped the file (e.g. cd /home/user/cipherbox)
4. run cipherbox.py
~~~
python cipherbox.py
~~~
